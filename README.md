## Featured Projects

### Robotic Quality Inspection and Sorting

An autonomous robotic quality-sorting system integrating 6-DoF object pose estimation, depth-based anomaly detection, motion planning, and robotic grasp execution.

**Technologies:** ROS 2, FoundationPose, Intel RealSense, MoveIt 2, xArm5, Python, OpenCV, Open3D

**Selected results:**

- 98.2% pose-estimation success
- 96.7% grasp success
- 94.7% anomaly-detection accuracy
- 89.8% end-to-end system success
- Reduced average cycle time from approximately 63 seconds to 41.2 seconds

> Repository and demonstration materials are being organized for public release.
